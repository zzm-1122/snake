# README 更新设计

## 目标

为贪吃蛇项目在仓库根目录提供一份中文 `README.md`，让新用户无需阅读源码即可了解项目、启动游戏和运行测试。

## 范围

- 新建根目录 `README.md`。
- 说明项目定位、核心玩法和食物类型。
- 给出直接在浏览器打开 `demo/index.html` 的运行方式。
- 给出 `node demo/test/script.test.js` 的测试命令。
- 列出键盘及移动端控制方式。

不修改游戏逻辑、样式、测试或既有演示页面。

## 内容结构

README 按以下顺序组织：项目简介、功能亮点、运行方式、操作说明、食物效果、测试方式与目录结构。内容与 `demo/README.md` 和当前实现保持一致，并将 `demo/README.md` 作为更具体的演示说明保留。

## 验证

核对 README 中的文件路径、启动命令、测试命令、食物类型和按键说明均能在仓库中找到对应实现。
