# 贪吃蛇小游戏（demo）

这是一个使用原生 `HTML + CSS + JavaScript` 实现的贪吃蛇小游戏仓库。

## 功能

- 网格化地图与蛇身移动
- 食物随机生成
- 碰撞检测（撞墙/撞自己）
- 分数统计与本地最高分（`localStorage`）
- 游戏结束后可快捷重开
- 事件音效（吃到食物 / 游戏结束 / 重开）

## 目录结构

- `index.html`：页面结构与 UI 容器
- `style.css`：页面与游戏区域样式
- `script.js`：核心游戏逻辑

## 本地运行

直接用浏览器打开 `index.html` 即可开始游戏。

## 操作方式

- `↑ ↓ ← →` 或 `W A S D` 控制方向
- 游戏结束后按 `空格键` 重新开始
