# 贪吃蛇小游戏（demo）

这是一个使用原生 `HTML + CSS + JavaScript` 实现的贪吃蛇小游戏仓库。

## 功能

- 网格化地图与蛇身移动
- 食物随机生成
- 碰撞检测（撞墙/撞自己）
- 合法进入“即将移走的尾巴格”时不会误判死亡
- 分数统计与本地最高分（`localStorage`）
- 游戏结束后可快捷重开
- 事件音效（吃到食物 / 游戏结束 / 重开）
- 控制按键会阻止页面默认滚动行为

## 目录结构

- `index.html`：页面结构与 UI 容器
- `style.css`：页面与游戏区域样式
- `script.js`：核心游戏逻辑
- `test/script.test.js`：无依赖回归测试脚本

## 本地运行

直接用浏览器打开 `index.html` 即可开始游戏。

## 测试

在 `demo/` 目录的上一级执行：

```bash
node demo/test/script.test.js
```

当前测试覆盖：

- 尾巴移动场景下的自撞判定
- `localStorage` 不可用时的启动容错
- 方向键、`WASD` 和空格键的默认行为拦截

## 操作方式

- `↑ ↓ ← →` 或 `W A S D` 控制方向
- 游戏结束后按 `空格键` 重新开始
